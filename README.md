# 🌌 Saksham Singh - 3D Cosmic Portfolio

Explore a cosmic portfolio with an interactive solar system, textured planets, spinning galaxies, black holes, and a glowing supernova. Click planets or black holes to zoom in; watch shooting stars, asteroid belts, and rotating mini galaxies. Built with Three.js, GSAP, and custom particle effects for an immersive web experience.

A visually stunning, interactive 3D web portfolio designed to showcase my skills in **Cybersecurity, Penetration Testing, and Full-Stack Development**. Built with modern web technologies, this portfolio features an immersive cosmic environment complete with an interactive solar system, spinning galaxies, black holes, and custom particle effects.

---

## ✨ Key Features

### 🪐 Immersive 3D Cosmic Environment (Three.js)
- **Interactive Solar System:** Textured planets with orbital paths and moons.
- **Dynamic Camera:** Click on planets or black holes to trigger smooth camera zoom and follow effects.
- **Rich Particle Systems:** Features shooting stars, asteroid belts, glowing supernovas, and rotating mini-galaxies.
- **Deep Space Elements:** Accretion disks around black holes, deep space nebulas, and custom lightning/thunderstorm particle clouds.

### 🎨 Advanced UI & Animations (GSAP & CSS3)
- **Scroll-Triggered Animations:** Smooth reveal effects and parallax scrolling powered by GSAP and ScrollTrigger.
- **Glassmorphism Design:** Modern aesthetic using CSS backdrop-filters, neon accent glows, and semi-transparent cards.
- **Interactive Project Cards:** Custom 3D tilt effects (`data-tilt`) that react to mouse movement.
- **Dynamic Navbar:** Responsive navigation that shrinks and applies blur effects on scroll.

### 🛡️ Content Highlights
- **Technical Arsenal:** Showcasing competencies in Python, Kali Linux, Metasploit, Burp Suite, React, and Secure Coding methodologies.
- **Featured Work:** Projects like *Web-Id-Changer*, *SQL/XSS Secure Login*, and *Alumno Connect (SIH 2025)*.
- **Experience:** Highlighting a Cybersecurity Internship at Ediglobe India and B.Tech CSE (Data Science) background.
